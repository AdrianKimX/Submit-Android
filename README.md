<h4>  Installation guide  </h4>

<h4> Component Configuration </h4>
<div class='components'>
 
Operating system: Windows 10 64-bit or higher<br>
Editor: Visual Studio Code<br>
Language / UI: Kotlin / Android XML<br>
Java JDK: Temurin OpenJDK 21.0.13<br>
Gradle (wrapper): 8.11.1<br>
Android Gradle Plugin (AGP): 8.10.1<br>
Kotlin Gradle Plugin: 2.1.20<br>
Android SDK: API 36 (compileSdk and targetSdk), minSdk 23<br>
Build output: Debug APK<br>
Test device: Android phones<br>
Project directory C:<br>
</div>
<b>The Gradle Wrapper (gradlew.bat) downloads and uses Gradle 8.11.1 by itself, so a global Gradle install in
PATH is not required.</b>
