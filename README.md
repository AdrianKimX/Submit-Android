# Component Configuration

1  <br>
2  -Operating system: Windows 10 64-bit or higher<br>
3  -Editor: Visual Studio Code<br>
4  -Language / UI: Kotlin / Android XML<br>
5  -Java JDK: Temurin OpenJDK 21.0.13<br>
6  -Gradle (wrapper): 8.11.1<br>
7  -Android Gradle Plugin (AGP): 8.10.1<br>
8  -Kotlin Gradle Plugin: 2.1.20<br>
9  -Android SDK: API 36 (compileSdk and targetSdk), minSdk 23<br>
10  -Build output: Debug APK<br>
11  -Test device: Android phones<br>
12  -Project directory C:<br>
The Gradle Wrapper (gradlew.bat) downloads and uses Gradle 8.11.1 by itself, so a global Gradle install in
PATH is not required.
